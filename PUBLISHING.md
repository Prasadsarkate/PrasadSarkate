# Premium GitHub Profile README — Prasad Sarkate

## Files
- `README.md`: profile layout with animated typing text, visual project cards, tech icons, stats and contact links.
- `assets/hero-banner.svg`: custom banner artwork.
- `assets/*-card.svg`: visual project cards.
- `.github/workflows/snake.yml`: optional contribution-snake workflow.

## Publish
1. Download and unzip this package.
2. Open https://github.com/prasadsarkate/prasadsarkate
3. Back up the existing README.md.
4. Upload/replace `README.md` and upload the `assets` folder.
5. Upload `.github/workflows/snake.yml` only if you want the optional contribution-snake workflow.
6. Commit to the repository's default branch and check https://github.com/prasadsarkate.

The repository must be public and named exactly `prasadsarkate` for its README to appear at the top of your profile.

## Important
- GitHub README is not a full custom website: GitHub sanitizes scripts and does not allow arbitrary CSS/JavaScript. This design uses supported Markdown/HTML and SVG images plus external animated/stat widgets.
- External widgets can rate-limit or go offline. If one fails, remove it or host a replacement yourself.
- Confirm all external links and current project details before publishing. Only claim skills and features you can demonstrate.
- This package does not edit your GitHub account or push files automatically.
